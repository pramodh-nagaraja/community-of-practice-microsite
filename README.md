# Community of Practice Microsite

A modern, responsive microsite for your Community of Practice built with React and Vite.

## Features

- **Responsive Design** - Works on all devices
- **Navigation** - Smooth scrolling to sections
- **Sections**: Home, About, Events, Resources, Members, Contact
- **Modern UI** - Clean, professional design with gradient hero

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open http://localhost:5173 in your browser

## Build for Production

```bash
npm run build
```

The production build will be in the `dist` folder.

## Customization

- Edit `src/App.tsx` to modify content
- Edit `src/App.css` to change styling
- Update `index.html` for page title and meta info
